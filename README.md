# Auto-Research Arena website

Static article, discovery catalogue, and selected research results for Auto-Research Arena.

The site is contained in `docs/`. GitHub Pages should publish branch `pages`, folder `/docs`. The `.nojekyll` file serves the existing HTML, CSS, JavaScript, and source downloads directly.

## Preview

```sh
python3 -m http.server 8000 --bind 127.0.0.1 --directory docs
```

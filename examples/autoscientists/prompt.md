# autoscientists

Read pinned runbook.md, launch.py, task-autoresearch and system templates. Run the native launcher/profile and team with the supplied task binding.

Prepare an isolated native workspace and, when required by the launcher, a private ClawInstitute instance with inherited authentication and a unique workshop. Record actual dependencies, model and native endpoint bindings in run-local public notes. Missing native service or supported subagent tooling is a setup failure, not permission to simulate roles.

The launcher creates the native task/profile, ten differentiated identities and workspace metadata. Read the benchmark binding first: full frozen task, current reference, immutable boundary, declared target, task eligibility and two measurement workers.

Keep three analysts, six experiment roles and a monitor. Each experiment agent claims, builds, evaluates through the supplied API helper, inspects results and publishes feedback itself. Preserve native discussion, queues, claims and scheduling, including the regular analyst barrier and the task profile's cold-start exception.

The launcher initializes local and shared champion records using the native champion format and supplied reference before roles start.

Feed complete canonical results back to native experiment history and shared posts, preserving source and launch identity. Compare the raw target strictly against the fresh champion and require task eligibility. The winning experiment agent performs native version-checked champion publication and atomic source copying; the orchestrator observes and logs it without duplicate promotion. Retain native multi-seed checks when selected. If the task forbids a requested confirmation seed, record the precise conflict and leave the candidate unconfirmed.

Run the native task-profile periodic meta-improvement hook every third execution cycle. Review experiments, conversations, queues and champion propagation.

Stop on zero KEEPs in the last ten experiments or the task cap, whichever comes first. Finish feedback and record the native stopping reason. Resume actual native sessions, workspace, history and champion; never reset stagnation.

For the auto-bracketing big-win trigger only, use `abs(old_target - new_target) / reference_target > 0.001`. Keep raw metrics, native KEEP comparisons, noise checks and midpoint/overshoot proposal generation unchanged.

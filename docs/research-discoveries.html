Training FLOPs

Which parts of training can do less arithmetic while reaching the quality target?

Lookup-augmented feed-forward networksSequential Search

A grouped feed-forward network is supplemented with learned token-indexed feature tables. At each depth, the input token selects a 1,024-dimensional vector from one of three tables assigned to different depth ranges. The hidden state gates that vector before the squared-ReLU nonlinearity, combining lexical features with contextual computation. Grouped channel mixing and separate attention key/value lookups complete the model’s use of stored token features.

Sequential Search’s complete program measures 56.66 million counted training FLOPs per token at validation BPB 1.04947, with 49.75 million parameters. The lookup tables supply capacity while the surrounding dense computation is reduced.

The counter excludes embedding gathers and several elementwise operations, so the result does not imply a proportional improvement in runtime. Attention, routing and readout changes also contribute to the complete program; the measurements do not isolate the lookup branch.

Muon with adaptive scalingSequential Search

Sequential Search forms an approximately orthogonal matrix update, tracks its squared-update history separately for every parameter, and uses that history to rescale each entry. It then restores the update’s overall norm.

The per-parameter statistics provide finer adaptation than row- or column-shared statistics and require a full matrix of second-moment state.

Decode latency

Which dependencies and operations determine the cost of each generated token?

Independent attention and MLP sublayersBeam Search

A Transformer depth position need not contain both attention and a feed-forward module. Beam Search’s decoder has four width-512 blocks, with an attention-only block at the second position and an MLP-only block at the third, while the first and last retain both. Three attention sublayers and three MLPs remain, together with four positions that keep their own residual and input-mixing gains. Training and decoding execute the same retained sublayers.

Beam Search’s program records 65.15 ms for a one-token prefill and 512 decoding steps, with validation BPB 1.04818. The same program’s full request takes 84.04 ms. These measurements include its BF16 serving weights, fused helpers and graph replay.

The active sublayers still alternate attention and MLP when flattened; this is not a new sandwich ordering. The model is trained with these omissions, and the complete-program measurement does not isolate their latency benefit or show that arbitrary pretrained models can lose the same sublayers.
